Aide & mode d'emploi

Démarrage rapide
  1. Choisissez le type de contenu en haut (Lien, Texte, Wi-Fi, Contact, E-mail, Téléphone).
  2. Remplissez les champs : l'aperçu se met à jour tout seul, rien à valider.
  3. Facultatif : ouvrez Personnaliser l'apparence pour les couleurs, formes, logo ou cadre.
  4. Choisissez Avec fond ou Transparent, le nom du fichier, puis Télécharger le PNG (ou SVG).
  5. Testez-le toujours avec un téléphone avant d'imprimer ou de diffuser.

Par défaut l'outil produit un QR code classique (noir sur blanc) : le plus lisible par tous les scanners.

Qu'est-ce qu'un QR code ?

Un QR code est une image qui contient du texte. Quand on le scanne avec l'appareil photo d'un téléphone, celui-ci lit ce texte et propose l'action correspondante : ouvrir un site, enregistrer un contact, se connecter au Wi-Fi…

Les QR codes créés ici sont statiques : le contenu est inscrit dans l'image. Il n'expire jamais, fonctionne sans limite de scans et sans connexion à un service tiers — mais il ne peut pas être modifié après impression. Vérifiez bien vos informations avant de diffuser.

Les trois gros carrés dans les coins sont les marqueurs : ils servent au scanner à repérer et redresser le code.

Les types de contenu
  • Lien : ouvre un site web. Le https:// est ajouté automatiquement si vous l'oubliez.
  • Texte : affiche un message libre (consigne, énigme, mot de passe d'une activité…).
  • Wi-Fi : le téléphone propose de rejoindre le réseau sans taper le mot de passe. Renseignez le nom exact du réseau (SSID), le mot de passe et le type de sécurité (WPA dans la plupart des cas).
  • Contact : crée une fiche (nom, société, téléphone, e-mail) que le téléphone propose d'enregistrer dans le répertoire.
  • E-mail : ouvre un nouveau message déjà rempli (destinataire, objet, corps).
  • Téléphone : prépare l'appel du numéro indiqué.

Conseil : plus le contenu est court, moins le QR est dense, donc plus il se scanne facilement et de loin.

Personnaliser l'apparence
  • Modèles rapides : cliquez une vignette pour appliquer d'un coup une combinaison couleurs + formes. La première est le style classique. ↺ Réinitialiser remet tous les réglages par défaut.
  • Couleurs : cliquez la pastille ronde d'un réglage pour ouvrir la palette, puis une couleur, ou Couleur libre… pour la choisir vous-même.
  • Modules : les petits carrés qui composent le code. Couleur unie ou dégradé (linéaire ou radial), et six formes au choix.
  • Marqueurs des coins : le contour et le centre se règlent séparément, en forme et en couleur.
  • Correction d'erreur : voir la section dédiée plus bas.

Règle d'or : gardez un fort contraste, code foncé sur fond clair. Un code clair sur fond foncé fonctionne sur beaucoup de téléphones, mais pas sur tous.

Logo au centre
  • Choisissez une icône de la galerie (24 icônes, couleur réglable) ou importez votre image (PNG, JPG, SVG).
  • Dès qu'un logo est présent, la correction d'erreur passe automatiquement au maximum pour compenser la zone masquée.
  • Retirer enlève le logo.

Un logo masque une partie du code : testez systématiquement le scan après l'avoir ajouté, et évitez les images très détaillées ou très claires.

Cadre avec texte
  • Cochez Encadrer le QR, ou cliquez directement un des exemples (un clic active le cadre).
  • Le texte affiché est celui du champ Texte sous le QR / du cadre (40 caractères max). Sans texte saisi, « SCANNEZ-MOI » s'affiche.
  • Les couleurs du cadre et du texte sont réglables.
  • Un cadre a toujours sa couleur comme fond : pour un export réellement transparent, n'utilisez pas de cadre.

Un cadre avec une consigne courte augmente nettement le nombre de scans sur une affiche.

Correction d'erreur

La correction d'erreur ajoute des données de secours à l'intérieur du QR code pour qu'un scanner puisse le lire parfaitement même s'il est déchiré, taché ou masqué par un logo.

  • Basse (~7 % récupérable) : code le moins dense, à réserver aux contenus courts sur support protégé.
  • Moyenne (~15 %) : réglage par défaut, bon compromis.
  • Haute (~25 %) : affichage extérieur, surface exposée aux salissures.
  • Maximale (~30 %) : imposé automatiquement avec un logo.

Plus la correction est haute, plus le code contient de modules : il devient plus dense, donc à imprimer un peu plus grand.

Exporter
  • PNG : image classique, pour un document, un diaporama ou un écran. Réglez la taille avec le curseur (256 à 2048 px) : plus c'est grand, meilleure est l'impression.
  • SVG : image vectorielle, agrandissable à l'infini sans perte. À privilégier pour l'imprimeur et les grands formats (affiche, kakémono).
  • Copier : place l'image dans le presse-papiers pour la coller directement dans un document.
  • Imprimer : ouvre la boîte d'impression avec le code seul, centré sur la page.
  • Fond : Avec fond utilise la couleur de fond choisie (blanc par défaut) ; Transparent supprime le fond, utile pour poser le code sur une image ou un aplat de couleur.
  • Le champ Nom du fichier définit le nom de tous les téléchargements.
Génération en lot

Pour créer plusieurs QR codes d'un coup (une classe, une série de salles, une liste de liens).

  1. Ouvrez Génération en lot.
  2. Saisissez une ligne par QR code, au format contenu;nom du fichier (le nom est facultatif).
  3. Vous pouvez aussi coller depuis un tableur (colonnes séparées par une tabulation) ou importer un fichier .csv / .txt.
  4. Cliquez Télécharger l'archive ZIP.
https://exemple.fr;accueil
https://exemple.fr/rh;rh
Bonjour !;message

Maximum 200 lignes. Le ZIP contient chaque code en PNG et SVG, avec l'apparence choisie au-dessus. Les noms en double reçoivent un suffixe (accueil, accueil-2).

Imprimer et afficher : bonnes pratiques
  • Taille : comptez environ 1 cm de côté par mètre de distance de lecture. Minimum conseillé : 2 cm pour un document tenu en main, 10 cm pour une affiche de couloir.
  • Marge : laissez une zone calme (blanche) autour du code, elle est comprise dans l'image exportée — ne recadrez pas au plus juste.
  • Support : évitez les surfaces brillantes ou plastifiées réfléchissantes, et les plis au milieu du code.
  • Hauteur : placez l'affiche à hauteur des yeux ; un code au sol ou trop haut se scanne mal.
  • Ajoutez toujours une consigne écrite à côté (« Scannez pour le menu ») : tout le monde ne devine pas où mène un code.
Affichage et accessibilité

Le bouton Affichage (en haut à droite) règle le thème clair/sombre, la taille du texte, les animations et le contraste renforcé. Ces préférences sont mémorisées sur l'appareil.

L'outil s'installe comme une application (bouton Installer dans Affichage, ou « Sur l'écran d'accueil » sur iPhone/iPad) et fonctionne ensuite hors connexion.

Problèmes fréquents
  • « Contenu trop long » : raccourcissez le texte, ou utilisez un lien court à la place d'une longue adresse.
  • Le code ne se scanne pas : augmentez le contraste, revenez à des modules carrés, retirez le logo, montez la correction d'erreur, ou imprimez plus grand.
  • Le logo n'apparaît pas : vérifiez le format de l'image (PNG, JPG ou SVG) et réessayez.
  • Copier ne fonctionne pas : certains navigateurs l'interdisent, téléchargez le PNG à la place.
  • Export PNG impossible : téléchargez le SVG, lisible par tous les logiciels de mise en page.
  • Une modification n'apparaît pas : rechargez la page en vidant le cache (Ctrl+Maj+R, ou Cmd+Maj+R sur Mac).
Confidentialité

Tout est calculé dans votre navigateur. Aucune donnée saisie — lien, mot de passe Wi-Fi, contact, logo importé — n'est envoyée sur un serveur, ni enregistrée ailleurs que sur votre appareil. L'outil fonctionne d'ailleurs entièrement hors connexion une fois chargé.
