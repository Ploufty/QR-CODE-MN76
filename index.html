Aide & mode d'emploi

Créer un QR code
  1. Choisissez un type : Lien, Texte, Wi-Fi, Contact, E-mail ou Téléphone.
  2. Remplissez les champs : l'aperçu se met à jour tout seul.
  3. Testez-le avec un téléphone avant de l'imprimer ou de le diffuser.
Les types de QR code
  • Lien : ouvre un site (le https:// est ajouté si oublié).
  • Texte : affiche un message libre.
  • Wi-Fi : le téléphone propose de se connecter au réseau, sans saisir le mot de passe.
  • Contact : ajoute une fiche (nom, société, téléphone, e-mail) au répertoire.
  • E-mail : ouvre un message pré-rempli. Téléphone : lance l'appel.
Personnaliser
  • Modèles rapides : cliquez une vignette pour appliquer une combinaison couleurs + style.
  • Couleur des modules : unie, ou dégradé (linéaire/radial) entre deux couleurs. Gardez un fort contraste avec le fond.
  • Style des modules et marqueurs (contour et centre) : formes et couleurs réglables séparément.
  • Correction d'erreur : plus elle est haute, plus le QR résiste aux dégâts, mais plus il est dense.
  • Logo : petite image au centre (correction forcée au maximum). Vérifiez toujours le scan.
  • Texte sous le QR : légende de 40 caractères maximum.
  • Taille du PNG : curseur côté aperçu, de 256 à 2048 px (impression grand format).
Exporter
  • PNG : image pour documents et écrans. SVG : vectoriel, idéal pour l'impression grand format.
  • Copier : place l'image dans le presse-papiers. Imprimer : ouvre la boîte d'impression.
  • Le champ « Nom du fichier » définit le nom des téléchargements.
Génération en lot

Saisissez une ligne par QR code au format contenu;nom. Vous pouvez aussi coller depuis un tableur (colonnes séparées par une tabulation) ou importer un .csv. Maximum 200 lignes. Le ZIP contient chaque QR en PNG et SVG, avec les couleurs et le style choisis ci-dessus.

https://exemple.fr;accueil
https://exemple.fr/rh;rh
Bonjour !;message
Problèmes fréquents
  • « Contenu trop long » : raccourcissez le texte ou le lien.
  • Le QR ne se scanne pas : augmentez le contraste, retirez le logo ou montez la correction d'erreur.
  • Copier ne marche pas : certains navigateurs l'interdisent, utilisez PNG.
  • Confidentialité : rien n'est envoyé sur un serveur, tout se calcule dans votre navigateur.
